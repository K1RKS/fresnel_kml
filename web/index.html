    API

    POST api/fresnel.cgi with Content-Type: application/json. The response is the KML file, or JSON with "format": "json".

    {
  "site_a": {"name": "TowerA", "lat": 37.0, "lon": -122.0, "agl_m": 30},
  "site_b": {"name": "TowerB", "position": "10S 597811 4100985", "asl_m": 412.5},
  "options": {"freq_ghz": 5.8, "color": "random", "terrain_check": true},
  "format": "kml"
}
    curl -X POST -H 'Content-Type: application/json' -d @req.json https://HOST/site/api/fresnel.cgi -o link.kml

    Each site takes lat/lon (decimal degrees by default; DMS and DDM strings also work) or one position string, and exactly one of agl_m or asl_m. GET api/fresnel.cgi?sources lists elevation sources; GET api/fresnel.cgi?parse=TEXT decodes a coordinate.

    Coordinates are WGS-84. Heights above sea level need no elevation lookup unless the terrain check is on.
